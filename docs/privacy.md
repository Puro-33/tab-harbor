# Tab Harbor 개인정보처리방침

시행일: 2026년 9월 7일

공개 페이지: [Tab Harbor 개인정보처리방침](https://tab-harbor.junghuncha40.chatgpt.site)

Tab Harbor는 사용자가 선택한 탭과 URL을 보관하고 나중에 다시 열기 위한 Chrome 확장 프로그램입니다.

## 처리하는 정보

저장 동작을 선택하면 탭의 URL, 제목, 순서, 고정 여부를 읽습니다. 사용자가 작성한 묶음 이름, 메모, 태그, 저장 시각, 다시 연 시각 및 보관 상태도 함께 저장합니다. 페이지 본문, 폼 입력, 쿠키, 페이지 저장소, 스크롤 위치를 별도로 읽지 않습니다.

URL은 검색어와 주소 매개변수를 포함한 원문으로 저장합니다. 주소 안에 인증 코드 등 민감한 값이 들어 있다면 그 값도 보관 정보와 JSON 백업에 포함될 수 있습니다. 민감한 URL은 저장하지 않거나 보관함에서 해당 기록을 삭제하세요.

## 저장과 이용

정보는 해당 Chrome 프로필에 속한 확장 프로그램의 IndexedDB에 저장하며, 탭 보관·검색·다시 열기 기능에 사용합니다. 개발자 서버, 광고업체 또는 분석 서비스로 전송하지 않습니다. 계정 가입이나 자동 기기 간 동기화는 없습니다. URL을 다시 열면 해당 웹사이트와 브라우저가 통상적인 방식으로 통신합니다.

## 사용자 제어

보관함에서 개별 묶음을 삭제할 수 있습니다. JSON으로 내보내면 사용자가 선택한 파일에 보관 정보가 저장되며, 다른 사람이 파일을 얻으면 URL과 메모를 읽을 수 있습니다. 백업 파일의 보관·공유·삭제는 사용자가 관리합니다. 확장 프로그램 또는 Chrome 프로필 삭제 시 브라우저에 저장된 기록이 제거될 수 있으므로 필요한 기록은 미리 백업하세요.

지원하는 브라우저에서는 저장 시 자동 정리를 줄이기 위한 지속 저장을 요청합니다. 허용 여부와 브라우저 설정에 따라 저장 공간이 정리될 수 있어, 필요한 기록의 JSON 백업을 별도로 보관하는 것이 좋습니다.

## 제한된 사용

Tab Harbor에서 처리하는 사용자 데이터의 사용과 이전은 [Chrome 웹 스토어 사용자 데이터 정책](https://developer.chrome.com/docs/webstore/program-policies/user-data)의 Limited Use 요구사항을 따릅니다. 사용자 데이터를 광고, 판매, 신용도 평가에 사용하지 않습니다.

## 권한

`tabs` 권한은 사용자가 지정한 탭들의 URL과 제목을 읽고 보관한 주소를 다시 여는 기능을 제공합니다. 방문한 페이지에 코드를 삽입하거나 자동으로 전체 방문 기록을 수집하지 않습니다.

## 문의와 변경

Chrome 웹 스토어 공개 게시 후에는 해당 항목의 개발자 연락처로 문의할 수 있습니다. 정보 처리 방식이 변경되면 이 방침과 확장의 안내를 함께 갱신합니다.
