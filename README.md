# Tab Harbor · 탭 보관함

Chrome 탭과 URL을 로컬 IndexedDB에 보관하고, 대기 목록에서 찾아 다시 여는 Manifest V3 확장입니다. 서비스 계정이나 원격 서버 없이 이 Chrome 프로필에 저장합니다.

## 개발

Node.js 22 이상을 사용합니다.

```sh
npm install
npm test
npm run check
npm run package
```

Windows PowerShell에서 `npm.ps1` 실행이 차단되면 같은 명령을 `npm.cmd`로 실행합니다. 실행 정책을 바꿀 필요는 없습니다. 아이콘 원본을 다시 만들 때는 `requirements-assets.txt`의 개발 의존성을 설치한 뒤 `python scripts/make-assets.py`를 실행합니다.

Chrome의 `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**로 `extension` 폴더를 선택합니다. 도구 모음 아이콘을 고정하면 팝업에서 저장하고 보관함을 열 수 있습니다.

## 데이터와 동작

- 현재 탭 또는 현재 창의 HTTP/HTTPS 탭을 이름 있는 묶음으로 저장합니다.
- 대기 목록을 검색하고 전체 또는 개별 주소를 다시 엽니다.
- 저장 후 닫기는 사용자가 선택했을 때만 실행합니다. DB 저장이 끝나기 전에는 원본 탭을 닫지 않습니다.
- 다시 열기는 웹 주소를 여는 기능입니다. 폼 입력, 페이지 내용, 로그인 상태, 뒤로 가기 기록, 스크롤 위치를 저장하지 않습니다.
- 내부 Chrome 페이지, 파일 및 실행 가능한 URL은 지원하지 않습니다. 제외·실패 항목을 표시합니다.
- JSON 백업은 URL을 포함합니다. 안전한 위치에 보관하세요. 이 Chrome 프로필이나 확장을 삭제하기 전에 백업하세요.
- 현재 보관 한도는 1,000개 묶음, 전체 10,000개 탭, JSON 기준 10 MB입니다. 한 묶음에 최대 1,000개 탭을 저장합니다. 내보낸 백업을 다시 가져올 수 있도록 저장·가져오기에 같은 한도를 적용합니다.

## 프로젝트 구조

- `extension/`: 스토어에 제출할 확장 소스. 외부 런타임 코드가 없습니다.
- `extension/lib/`: 데이터 모델, IndexedDB 저장소, 저장·복원 서비스.
- `tests/`: URL 검증, 저장소, Chrome API 실패 시 동작 테스트.
- `scripts/`: 패키지 검사, 아이콘 생성, 재현 가능한 ZIP 생성.
- `docs/`: 개인정보 안내와 스토어 제출 자료.
- `dist/`: 생성된 ZIP과 SHA-256. 소스 저장소에는 포함하지 않습니다.

`npm test`는 브라우저의 실제 동작을 대신하지 않습니다. 설치·팝업·브라우저 재시작·실제 탭 복원은 별도로 확인하며 결과를 릴리스 기록에 남깁니다. 스토어 게시 완료는 공개 항목 페이지와 개발자 대시보드 상태로 검증해야 합니다.
